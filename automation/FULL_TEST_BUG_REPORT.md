## 🧱 Architectural Observations

### 3. State Propagation Bypass in PluginService

- **Observation**: For plugins targeting `worker`, `update_config` makes a direct HTTP call instead of relying on the `LifecycleBus`.
- **Note**: This deviates from the project's event-driven architecture where `LifecycleBus` should be the source of truth. If the HTTP call succeeds but the bus update is skipped, other services might have out-of-date state.
